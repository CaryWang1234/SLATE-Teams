# 技能：简历全面诊断（resume_diagnose）

## 用途

收到简历文本 + 目标岗位后，按本流程输出一份完整诊断报告。

## 输入

- 简历原文（粘贴文本、md/docx/pdf 文件；pdf 用 pdf_tool 提取、docx 用 word 相关工具读取）
- 目标 JD 原文或岗位方向描述

## 流程

1. **六秒测试**：只看排版与加粗标题，写出"第一眼留下了什么印象、什么被跳过了"
2. **结构检查**：版面顺序是否把最强证据放在最显眼位置；无关内容占版面比例
3. **逐条体检**：对每条经历套用公式「动词开头 + 做了什么 + 方法/技术 + 可验证结果」，缺哪部分标哪部分，并给改写示范
4. **JD 匹配**：按 knowledge/《JD 拆解与匹配方法》列清单打分（强/弱/缺口）
5. **汇总输出**：

```
## 总评
<一句话 + 预估初筛通过率：高/中/低，给依据>

## 必改（≤5 条，按投入产出排序）
| # | 位置 | 病因 | 改写示范 |

## 可选优化
## 缺口与对策
## 建议投递策略
<直投 / 改后再投 / 不建议投该岗，理由>
```

## 约束

- 改写示范必须保留用户真实经历，不添加未证实的数字与职位
- 诊断对文本负责：读不到原文（图片简历解析失败）就直说，不猜内容
- 报告 600 字以内，超出说明啰嗦了
