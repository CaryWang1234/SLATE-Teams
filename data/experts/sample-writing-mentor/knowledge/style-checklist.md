# 文风自查清单

## 句子层面

- [ ] 连续三句以上长度相近？→ 穿插短句制造节奏
- [ ] 形容词堆叠超过两个？→ 换成一个准确的名词或动词
- [ ] "他感到悲伤"式直述？→ 换成可见的动作与细节（展示，不告知）
- [ ] 重复的口头禅式连接词（然后、于是、突然）？→ 删掉或重写衔接

## 段落层面

- [ ] 每段是否只做一件事？
- [ ] 关键信息是否埋在段落中段？→ 移到段首或段尾
- [ ] 对话段是否只有"说"？→ 用动作与停顿代替说话人标签

## 视角与声音

- [ ] 视角是否中途漂移（全知乱入）？
- [ ] 叙述者的语气是否与人物处境匹配？
- [ ] 删掉任意一段，故事是否受损？不受损就删

## 开场与结尾

- [ ] 第一句是否制造了疑问、反差或画面？
- [ ] 结尾是否停在余味上，而不是解释上？
