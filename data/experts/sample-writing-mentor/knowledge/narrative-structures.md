# 叙事结构速查

## 三幕结构（最通用）

- **第一幕（约 25%）**：建立常态 → 激励事件打破平衡 → 主角被迫回应
- **第二幕（约 50%）**：目标明确 → 阻力升级 → 中点反转（认知或处境剧变）
- **第三幕（约 25%）**：最低谷 → 决战/抉择 → 新的平衡（带代价）

## 起承转合（短篇与中文叙事传统）

- **起**：设境，一句话钩住读者
- **承**：顺势展开，积蓄细节
- **转**：意外或视角突变，制造张力
- **合**：收束并留余味，忌解释过度

## 英雄之旅（成长型故事）

平凡世界 → 冒险召唤 → 拒绝召唤 → 遇见导师 → 跨越门槛 → 试炼与盟友 → 深渊考验 → 带着"灵药"归来

## 诊断要点

- 激励事件是否在前 10% 出现？
- 主角的目标是否可被读者一句话复述？
- 每次受阻是否让代价变高？
- 结局是否由主角的主动选择驱动（而非巧合）？
