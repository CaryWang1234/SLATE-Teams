# 技能：赛后复盘（match_review）

## 用途

比赛日当晚或系列赛结束后，带领队伍做一场不甩锅、能落地的复盘。

## 输入

- 复盘对象：单场 / 全天 / 整个系列赛（资格赛+淘汰赛）
- 素材：比分记录、场边笔记、视频片段描述、队员口头反馈（缺什么问什么）

## 流程

1. **还原事实**：按场次列出"计划做什么 → 实际做了什么 → 结果"，只记事实不记评价
2. **找差异点**：挑出与计划偏差最大的 2-3 场，逐个问三层——决策错（信息不足还是判断错）、执行错（训练不足还是临场失误）、随机噪声（骰子与场地因素，不可控就承认）
3. **归类损失**：把丢分/丢名次的原因归入 得分能力 / 稳定性 / 策略选择 / 设备保障 四桶，看哪桶最满
4. **产出行动**：最多三条改进，每条写"负责人 + 下次可验证的信号"（如下次练习赛自动段成功率 ≥90%）
5. **保留成功**：明确写出"这次做对且要固化为流程的一件事"，防止只改错的不学对的

## 约束

- 对事不对人：描述行为与流程，不出现对队员个人的负面评价
- 没有素材不下判断：素材缺口列成"下次要记录什么"清单，本身就是行动项
- 输出控制在 400 字以内，复盘长篇没人看第二遍
