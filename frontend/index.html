上下文与项目

调整上下文上限和项目宪法

内置模型与已填窗口的模型，「自动」各自取标称窗口的八成（不吸附到滑杆档位），这一档只给完全没有窗口信息的模型兜底。要单独调某个模型，用「模型配置」里该行的「最大上下文」：滑杆粗选、旁边的数字框可以填精确值、本地/自定义端点还能「探测窗口」。压缩阈值与上下文条按同一个数计算。
把宪法摘要、上下文片段、任务描述、约束与交付要求整合成一份可交付 Prompt。收起后再次打开，已写内容仍保留。

自动推进

回复疑似停顿（过短只表态，或只陈述计划而不调用工具）时，由审阅模型补出工具或技能调用；Autopilot 用完轮数时自动提醒模型继续

AI 辅助功能

除对话、团队讨论、提示词工厂外，所有会自行调用模型的功能都在这里：关闭即不再发请求，所选模型也只影响该项

「自动推进」的审阅模型与「后台任务」的自动续跑在各自区块设置，此处不重复

通知

大任务结束时的音效与系统通知（目标模式、团队讨论、工作流完成时触发）

后台任务

长耗时命令（实验服务器、编译训练）的独立通道：启动后立即返回，不占用对话；结束或命中触发条件时回传消息

每个对话最多自动续跑 3 次；关闭后消息仍保留，下次发送时一并交给模型

多任务与项目

切换项目不再中断正在生成的对话：离开的那场继续后台运行，结果进入右栏任务中心

关闭后恢复原行为：切换会话即中断当前生成。停止按钮在任何设置下都只停当前这一场
同项目并行会让两场同时改同一批文件，出问题难以定位来源；未开启工作区隔离时建议保持 1

通用 UI 实验性

实验性布局：极简 Codex 风格，功能入口收进左侧导航栏，对话更聚焦

开启后顶栏与左右面板收进左侧导航栏；空对话时输入框居中，消息区限宽 720px。此模式仍在探索，布局与入口位置可能随版本调整，可随时在此关闭还原。

自定义主题

改配色、板块透明度、字体（可导入自定义字体文件）与背景图；开启期间深色/浅色切换锁定，关闭即整套回到内置主题

配色只填四个源色，其余色值由它们按亮度与对比度算出来：正文与三个次要层级都会被拉到能读的清。开启期间顶栏的明暗按钮与 Ctrl+D 不生效，点它会说明原因。
点一个预设就把整套源色填进下面的色板，之后仍可逐格改；改过之后不再属于任何预设
系统已安装的字体族按名称直接使用；下方可导入本机字体文件。某台机器上既未安装也未导入的字体将回落到系统默认
本机还没有导入的字体
字体文件只存在本机 data/theme/fonts/，不进对话记录、也不复制到另一台设备。只收单个 .woff2 / .woff / .ttf / .otf（16MB 以内）；只导入一个字重时，粗体与斜体由浏览器模拟
面板、卡片、输入框与助手气泡这一层底色的不透明度。100% 是实色；调低会透出页面底色，铺了背景图时也能透出图。用户自己的气泡与代码块始终保持实色，正文不受影响
本机还没有背景图
图片存在本机 data/theme/ 里，不进对话记录、也不复制到另一台设备。遮罩浓度是底色压在图上的不透明度：过低会使正文压在图上，过高则等于没有背景图。
正在问 Wallpaper Engine…
把 Wallpaper Engine 当前壁纸的预览图取来作为上方背景图。只读取它在自己目录中写入的配置与 preview 图，不启动它，也不更改它的设置。Wallpaper Engine 更换壁纸后此处不会自动跟随，需再次点取；视频与场景壁纸取到的是其静态预览，仅有动态预览时取 gif（该图会在界面后持续播放）。

        欢迎使用 SLATE Teams · 智能工作台
        
      

      

        
本地 AI 协作调度台：把灵感研磨成方案，再交给模型自主执行。以下是六个最常用的入口：

        

          

            
            

              多模型对话
              
顶栏切换模型，@ 提及文件或技能，Enter 发送。历史侧栏支持搜索与导出

            

          

          

            
            

              目标模式
              
输入区「目标模式」按钮开启：模型自主多轮调用工具直至任务完成，大任务自动建 TODOLIST。

            

          

          

            
            

              磨墨模式
              
输入 /grind 想法：AI 三段式追问，把粗糙想法研磨成结构化任务书，一键送入目标模式

            

          

          

            
            

              内置工具
              
文件读写编辑、终端沙箱、联网搜索、PPT/Word/Excel 生成等 35 个工具，高危命令需审批。

            

          

          

            
            

              记忆与知识库
              
「记忆」按钮管理长期记忆与用户画像；左侧项目栏可扫描生成项目导览与规则手册。

            

          

          

            
            

              更多面板
              
顶栏对话（多模型聊天与工具调用）、团队（多席位辩论与工作流）、黑板（卡片式逻辑链）、扩展（技能 / 工具 / MCP / 专家包 / Actions）、设置（模型/上下文 / 备份）；提示词工厂不再占页签，入口在输入框上方的工具行
